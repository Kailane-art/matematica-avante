Funções

O que é uma função?

Uma função é uma relação matemática que associa cada elemento de um conjunto de entrada a exatamente um elemento de um conjunto de saída. Ela descreve como uma quantidade depende de outra.

Regra de associação

Imagine uma máquina: você informa um número, a regra realiza uma operação e apresenta um resultado. Se a regra for somar 3, a entrada 2 produz a saída 5.

Exemplo

A relação f(x) = x + 3 é uma função. Para cada valor escolhido para x, existe um único resultado correspondente.

Atenção

Uma mesma entrada não pode produzir duas saídas diferentes dentro da mesma função. Entradas diferentes, porém, podem produzir a mesma saída.

Domínio, contradomínio e imagem

Toda função envolve conjuntos que ajudam a identificar de onde vêm os valores de entrada e onde estão os possíveis resultados.

Domínio

É o conjunto de valores que podem ser usados como entrada da função. Costumamos representar esses valores pela variável x.

Contradomínio

É o conjunto definido como destino das possíveis saídas da função.

Imagem

É o conjunto dos valores que a função realmente produz. A imagem está contida no contradomínio.

Exemplo

Se f(x) = x², com domínio {−2, −1, 0, 1, 2} e contradomínio dos números naturais, a imagem é {0, 1, 4}.

Lei de formação

A lei de formação é a regra matemática que determina como calcular a saída de uma função a partir de cada entrada.

Representação

Uma função pode ser escrita como f(x) = 2x + 1. A letra x representa a entrada, enquanto f(x) representa o valor de saída.

Como interpretar

A regra indica que devemos multiplicar o valor de entrada por 2 e depois somar 1.

Exemplo

Para x = 3: f(3) = 2 · 3 + 1 = 7. Portanto, a saída correspondente a 3 é 7.

Calculando valores de uma função

Calcular o valor de uma função significa substituir a variável de entrada pelo número indicado e realizar as operações da expressão.

Exemplo resolvido

Considere f(x) = 3x − 4. Para descobrir f(5), substituímos x por 5: f(5) = 3 · 5 − 4 = 15 − 4 = 11.

Entrada negativa

Se x = −2, então f(−2) = 3 · (−2) − 4 = −6 − 4 = −10. Os parênteses ajudam a preservar o sinal.

Dica

Respeite a ordem das operações e substitua todas as ocorrências da variável.

Plano cartesiano

O plano cartesiano permite localizar pontos usando pares ordenados. Ele é formado por dois eixos numéricos perpendiculares.

Eixo horizontal

É o eixo x, também chamado de eixo das abscissas. Ele indica a primeira coordenada do ponto.

Eixo vertical

É o eixo y, também chamado de eixo das ordenadas. Ele indica a segunda coordenada.

Pares ordenados

Um ponto é indicado por (x, y). Por exemplo, o ponto (2, 3) fica duas unidades à direita e três unidades acima da origem.

Origem

É o ponto de encontro dos eixos, representado por (0, 0).

Gráficos de funções

O gráfico de uma função é a representação visual dos pares ordenados (x, f(x)) no plano cartesiano.

Construção

Escolhemos alguns valores para x, calculamos f(x) e marcamos os pontos correspondentes no plano cartesiano.

Exemplo

Para f(x) = x + 1, alguns pares são (0, 1), (1, 2) e (2, 3). Ao marcar esses pontos, obtemos parte de uma reta.

Leitura do gráfico

O eixo horizontal mostra as entradas e o vertical mostra os valores correspondentes da função. Cada ponto do gráfico representa um par entrada-saída.

Função afim

A função afim é definida por f(x) = ax + b, em que a e b são números reais. Seu gráfico é uma reta.

Coeficientes

O número a é o coeficiente angular e indica a inclinação da reta. O número b é o coeficiente linear e indica onde a reta cruza o eixo y.

Exemplo

Em f(x) = 2x + 3, temos a = 2 e b = 3. Quando x = 0, f(0) = 3, então a reta cruza o eixo vertical no ponto (0, 3).

Comportamento

Se a > 0, a função é crescente. Se a < 0, é decrescente. Se a = 0, a função é constante.

Função quadrática

A função quadrática, também chamada de função do segundo grau, tem a forma f(x) = ax² + bx + c, com a diferente de zero.

Gráfico

O gráfico de uma função quadrática é uma parábola. Se a > 0, ela tem concavidade voltada para cima; se a < 0, para baixo.

Coeficientes

O coeficiente a determina a concavidade. Os coeficientes b e c também influenciam a posição da parábola.

Exemplo

Na função f(x) = x² − 4x + 3, temos a = 1, b = −4 e c = 3. Como a é positivo, a parábola tem concavidade para cima.

Zeros ou raízes da função

O zero de uma função é um valor de x para o qual a saída é igual a zero. No gráfico, corresponde ao ponto em que a curva cruza ou toca o eixo x.

Função afim

Para f(x) = 2x − 6, fazemos 2x − 6 = 0. Assim, 2x = 6 e x = 3. O zero da função é 3.

Função quadrática

Os zeros de ax² + bx + c podem ser encontrados resolvendo a equação do segundo grau, frequentemente pela fórmula de Bhaskara.

Interpretação

Uma função pode ter nenhum, um ou mais zeros, dependendo de sua expressão e de seu domínio.

Crescimento e decrescimento

Uma função é crescente em um intervalo quando seus valores aumentam à medida que a entrada aumenta. É decrescente quando os valores diminuem.

Função crescente

Na função f(x) = 2x, quando x aumenta, f(x) também aumenta. Por exemplo: f(1) = 2 e f(3) = 6.

Função decrescente

Na função f(x) = −x + 5, quando x aumenta, f(x) diminui. Por exemplo: f(1) = 4 e f(3) = 2.

Na função quadrática

Uma parábola pode ser decrescente em uma parte do domínio e crescente em outra, ou o contrário. Isso depende da posição do vértice e da concavidade.
