Álgebra

Linguagem algébrica

A linguagem algébrica representa situações matemáticas usando letras, números e operações. As letras representam valores que podem ser desconhecidos ou variar.

Da linguagem comum para a algébrica

O dobro de um número: 2x.

Um número aumentado em 5: x + 5.

A metade de um número: x ÷ 2.

Por que usar letras?

Elas permitem escrever regras gerais e resolver problemas mesmo quando ainda não conhecemos o valor de uma quantidade.

Expressões algébricas

Uma expressão algébrica é uma combinação de números, letras e operações matemáticas, sem necessariamente apresentar uma igualdade.

Exemplos

3x + 2 é uma expressão algébrica.

5a − 4b é outra expressão algébrica.

Termos

Os termos são separados pelos sinais de adição ou subtração. Em 3x + 2, os termos são 3x e 2.

Atenção

Em 4x, a multiplicação entre 4 e x está indicada mesmo sem o símbolo ×.

Valor numérico de uma expressão

Para encontrar o valor numérico, substituímos cada letra pelo número indicado e efetuamos as operações respeitando a ordem correta.

Exemplo

Considere 2x + 3, com x = 4.

Substituindo: 2 × 4 + 3 = 8 + 3 = 11.

O valor numérico da expressão é 11.

Dica

Use parênteses ao substituir valores negativos para evitar erros de sinais.

Monômios

Monômio é uma expressão algébrica formada por um único termo. Ele possui um coeficiente numérico e uma parte literal, formada por letras e expoentes.

Exemplo

Em −5x²y, o coeficiente é −5 e a parte literal é x²y.

Grau do monômio

Quando há uma única variável, o grau é seu expoente. Em 3x², o grau é 2.

Com mais de uma variável, somamos os expoentes. Em 2a³b², o grau é 3 + 2 = 5.

Monômios semelhantes

Possuem a mesma parte literal, com as mesmas variáveis elevadas aos mesmos expoentes. Exemplo: 3x² e −7x².

Polinômios

Polinômio é uma expressão algébrica formada pela soma ou subtração de monômios. Cada parcela é chamada de termo.

Exemplo

4x² − 3x + 7 é um polinômio com três termos.

Classificação pelo número de termos

Monômio: um termo. Binômio: dois termos. Trinômio: três termos.

Grau do polinômio

É o maior expoente da variável depois de simplificar a expressão. Em 4x³ + 2x − 1, o grau é 3.

Operações com polinômios

Podemos somar e subtrair polinômios agrupando termos semelhantes. Na multiplicação, aplicamos a propriedade distributiva.

Adição

(3x + 2) + (2x + 5) = 5x + 7.

Subtração

(5x + 6) − (2x + 1) = 3x + 5. Ao retirar os parênteses precedidos de menos, os sinais dos termos internos mudam.

Multiplicação

2x(x + 3) = 2x² + 6x. O fator de fora multiplica cada termo de dentro dos parênteses.

Produtos notáveis

São multiplicações algébricas que aparecem com frequência e podem ser resolvidas usando fórmulas conhecidas.

Quadrado da soma

(a + b)² = a² + 2ab + b².

Quadrado da diferença

(a − b)² = a² − 2ab + b².

Produto da soma pela diferença

(a + b)(a − b) = a² − b².

Exemplo

(x + 3)² = x² + 6x + 9.

Fatoração

Fatorar é transformar uma expressão em um produto de fatores. É uma operação inversa ao desenvolvimento de produtos.

Fator comum

6x + 9 = 3(2x + 3). O fator comum 3 foi colocado em evidência.

Diferença de dois quadrados

a² − b² = (a + b)(a − b).

Trinômio quadrado perfeito

a² + 2ab + b² = (a + b)².

Equações do primeiro grau

Uma equação é uma igualdade que contém uma ou mais incógnitas. Resolver significa encontrar o valor que torna a igualdade verdadeira.

Exemplo resolvido

2x + 4 = 12.

Subtraindo 4 dos dois lados: 2x = 8.

Dividindo os dois lados por 2: x = 4.

Princípio da igualdade

O mesmo valor deve ser somado, subtraído, multiplicado ou dividido nos dois lados da igualdade (com divisão por número diferente de zero).

Sistemas de equações

Um sistema reúne duas ou mais equações que devem ser verdadeiras ao mesmo tempo. A solução é o conjunto de valores que satisfaz todas elas.

Exemplo

x + y = 10

x − y = 2

Somando as equações: 2x = 12, então x = 6. Substituindo na primeira: 6 + y = 10, logo y = 4.

Métodos de resolução

Os métodos mais comuns são substituição, adição (eliminação) e comparação.
